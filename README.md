- **Menu dọc bên trái tự thu gọn / mở rộng:** Nhường tối đa màn hình cho phim, trượt mở hiện tên khi bấm phím Trái.

- **Trình phát tối giản kiểu Netflix:** Thanh tiến trình màu đỏ mỏng, tua nhanh 10 giây, tự chuyển tập và lưu lịch sử đang xem dở (đã loại bỏ hoàn toàn phần dịch/đọc AI).
