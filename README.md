# VietMovie TV v2.4 (Giao Diện Netflix Mượt + Tìm Kiếm Tức Thì + Lọc Quốc Gia & Thể Loại + Bảng Chọn Giọng AI)

- **Giao diện kiểu Netflix:** Bo tròn toàn bộ thẻ phim (`CardView`) & nút bấm, hiệu ứng phóng nổi mượt khi lướt remote, nền backdrop đổi mượt theo phim đang chọn, tối ưu `DiffUtil` + nén ảnh Coil cho Android TV.
- **Tìm kiếm tức thì:** Gõ chữ là tự động hiện phim tương ứng ngay bên dưới (debounce 0.35s).
- **Lọc Quốc gia & Thể loại ở mọi mục:** Áp dụng linh hoạt cho tất cả danh mục và tìm kiếm.
- **Ưu tiên Thuyết Minh thật & Giọng AI 1 chạm:** Gắn thẻ `TM` / `LT`, đẩy server Thuyết Minh thật lên đầu; bấm **Giọng** mở bảng hiển thị toàn bộ giọng AI miễn phí để chọn trực tiếp kèm nghe thử, không cần cài đặt hay nhập API Key.
